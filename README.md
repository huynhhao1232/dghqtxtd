# EduEval (Laravel)

Hệ thống đánh giá hiệu quả công việc — bản Laravel (parity với Django trong thư mục gốc).

Xem [DEPLOY.md](DEPLOY.md) để chạy local và deploy Tentent.

```bash
composer install
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Đăng nhập demo: `lanhdao` / `Demo@123`
